# Домашнее задание: история сообщений WebSocket

В `serve/main.py` добавлено сохранение всех сообщений в `serve/chat_history.txt`. При подключении пользователя сервер отправляет последние 20 сообщений. После перезапуска история читается из файла.

## Запуск

1. Установить библиотеку: `pip install websockets`
2. Из папки `practic` запустить сервер: `python serve/main.py`
3. В другом терминале из папки `practic/client` запустить: `python -m http.server 8000`
4. Открыть `http://localhost:8000`, ввести имя и отправить сообщения.
5. Открыть вторую вкладку или перезапустить сервер и проверить, что последние сообщения появились снова.

Файл `chat_history.txt` создаётся автоматически после первого сообщения.
